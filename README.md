# Personal CV & Portfolio Homepage

Responsive portfolio template built with plain HTML and CSS for GitHub Pages.

## Files
- `index.html` — page content
- `style.css` — layout, colours, typography, mobile styling
- `assets/cv.pdf` — add your CV PDF here for the Download CV button

## Personalise
1. Edit `index.html` and replace `Your Name`, `[placeholder text]`, `YOUR-USERNAME`, and example repository links.
2. Add your actual email, LinkedIn URL, projects, skills, roles, and education.
3. Put a PDF CV in `assets/` named `cv.pdf`, or change/remove the download button.
4. Change the colour palette in the `:root` section at the top of `style.css`.
5. Preview locally by opening `index.html` in a browser.

## Publish on GitHub Pages
### Profile homepage
1. Create a repository named exactly `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `style.css`, and the `assets` folder to the repository root.
3. Go to **Settings → Pages** and publish from the `main` branch and `/ (root)` if prompted.
4. Your site will be available at `https://YOUR-USERNAME.github.io/`.

### Project page
Upload these files to a repository such as `portfolio`, then go to **Settings → Pages** and choose **Deploy from a branch**, `main`, and `/ (root)`. The site will appear at `https://YOUR-USERNAME.github.io/portfolio/`.

Before publishing, replace all placeholders and confirm you are comfortable making the listed contact details public.
